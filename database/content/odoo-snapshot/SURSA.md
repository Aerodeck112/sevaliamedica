# Instantaneu al siteului public www.sevalia.ro

- Preluat: 2026-10-25, cu `Accept-Language: ro-RO` și cookie `frontend_lang=ro_RO`, prin `tools/audit/crawl.py`
- Platforma sursă: Odoo (meta `generator=Odoo`)
- `pages.json`: URL → cod HTTP, URL final, titlu, meta description, fișierul HTML salvat în `pages/`
- `images/`: imaginile referite de pagini, salvate nemodificate; `index.json` mapează calea originală la fișier și SHA-256
- `assets/web.assets_frontend.min.css`: foaia de stil publicată (Bootstrap MIT + Odoo LGPL-3 + personalizările clinicii)

Acest instantaneu este sursa importului inițial în CMS. Nu conține date de pacienți.
